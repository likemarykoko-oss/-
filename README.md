# HR-агент Авито (проект)

Агент обрабатывает отклики на объявления Авито быстрее человека, ведёт
кандидата по анкете, отсекает неподходящих по формальным признакам,
записывает на собеседование и передаёт решения руководителю и админам.

## Принятые решения

- Решение по мастерам принимает руководитель, глядя на фото работ.
- Возраст 19–35 — внутренний ориентир, не причина отказа в переписке.
- Подключение — официальный Avito API.
- Чат «админы коко» — витрина записей; занятость живёт в таблице.
