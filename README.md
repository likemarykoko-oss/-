# HR-агент Авито (проект)

Агент обрабатывает отклики на объявления Авито быстрее человека, ведёт
кандидата по анкете, отсекает неподходящих по формальным признакам,
записывает на собеседование и передаёт решения руководителю и админам.

## Принятые решения

- Решение по кандидатам принимает управляющий, глядя на фото работ.
- Владелец получает деньги, простой и недельную сводку — но не анкеты.
- Возраст 19–35 — внутренний ориентир, не причина отказа в переписке.
- Подключение — официальный Avito API.
- Занятость времени знают админы: агент сначала запрашивает окна в чате,
  и только потом называет их кандидату.
- Баланс отслеживается заранее, по сигналу «Надо пополнить», а не по факту
  скрытых объявлений.
