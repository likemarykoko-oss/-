# reels-motion — сложный монтаж с анимацией

Навык для Claude Code и всё к нему: оживающие титры, кинетическая типографика,
счётчики цифр, анимированная инфографика и вставки со скриншотами поверх снятого
видео. Сборка — через Remotion и HyperFrames.

## С чего начать

Читайте **[НАЧНИ-ОТСЮДА.md](НАЧНИ-ОТСЮДА.md)** — там обзор пакета и порядок действий.

Дальше по шагам:

1. **[УСТАНОВКА.md](УСТАНОВКА.md)** — два плагина и программы, 15 минут, один раз.
   Или запустите установщик — он скопирует навык в `~/.claude/skills/`, проверит
   программы и скачает модель распознавания речи:
   `bash установить.sh` на Mac, `powershell -ExecutionPolicy Bypass -File .\установить.ps1`
   на Windows.
2. **[КАК-ДАВАТЬ-МАТЕРИАЛЫ.md](КАК-ДАВАТЬ-МАТЕРИАЛЫ.md)** — как снимать и что
   присылать, чтобы вышло с первого раза.
3. Снять видео, положить в папку, сказать Claude что смонтировать.

## Главное правило

Анимация занимает **10–15% ролика**: заголовок, одна-две вставки, финал.
Когда движется всё подряд — получается шаблон из стоков, а не ваш ролик.
