# Журнал агента. Версия 2

## Что изменилось

В версии 1 предлагалась таблица, которая хранила занятость слотов. В версии 2
**занятость хранят админы**: агент спрашивает у них свободные окна и только
потом называет время кандидату. Двойная запись при таком порядке невозможна —
агент физически не может назвать время, которого админы не дали.

Поэтому таблица остаётся, но в другой роли: это **журнал**, а не расписание.
Занятость в нём не ведётся. Нужен он для трёх вещей, которые из телеграм-чата
не достать:

1. **Не потерять кандидата.** Кто на какой стадии, кто ждёт ответа
   управляющего вторые сутки, кому не ответили админы.
2. **Не задваивать людей.** Один и тот же человек откликается на два-три
   объявления — проверка по номеру телефона.
3. **Понимать, работает ли схема.** Сколько откликов дошло до собеседования
   и до выхода на работу.

Плюс два служебных листа: объявления (там живёт признак планового скрытия) и
FAQ (оттуда агент берёт ответы про деньги и условия).

Это один документ Google Sheets. Люди в него могут не заходить вообще — его
ведёт агент.

## Лист 1. «Кандидаты»

| Поле | Пример |
|------|--------|
| Дата отклика | 25.08.2026 14:12 |
| Объявление | Мастер (парикмахер) |
| ФИО | Иванова Мария Петровна |
| Телефон | +79001234567 |
| Возраст | 27 |
| Специализация | парикмахер |
| Опыт, лет | 4 |
| Обучение | курс «Базовая стрижка», сертификат |
| Фото работ | 3 (ссылка) |
| Статус | новый / анкета собрана / у управляющего / одобрен / ждём окна от админов / окна предложены / записан / передан админу для согласования / был на собеседовании / вышел / отказ / не отвечает |
| Решение управляющего | да / нет / — |
| Предложенное время | 27.08.2026 10:00 |
| Итог | записан на 27.08 10:00 / контакт передан админу |
| Ссылка на диалог Авито | … |
| Комментарий | … |

Телефон — ключ дедупликации.

**Сигналы «застряло»**, по которым агент напоминает сам:
- «у управляющего» дольше 4 рабочих часов → напоминание управляющему;
- «ждём окна от админов» дольше 2 часов → напоминание в чат админов,
  дольше 4 → управляющему;
- «окна предложены», кандидат молчит сутки → сообщение админам `C6`.

## Лист 2. «Модели»

| Объявление (ID) | Услуга | Имя | Телефон | Фото «до» | Требования объявления | Предложено | Итог | Дата |
|---|---|---|---|---|---|---|---|---|

Поле «Требования объявления» — дословно из текста объявления (длина,
исходный цвет, состояние). Именно по нему агент сверяет фото «до».
**Поле пустое → агент не оценивает фото сам, а отправляет его админам
на «да/нет».**

## Лист 3. «Объявления»

| ID | Название | Тип | Условия из объявления | Статус | Плановое скрытие | Причина неактивности | Проверено |
|---|---|---|---|---|---|---|---|
| … | Модель на окрашивание | модели | цитата: длина, цвет, цена для модели | скрыто | **да** | админы ответили «все модели найдены» 25.08 | 25.08 18:00 |

Поле «Условия из объявления» — дословные строки про оплату, формат и
длительность. Из него агент цитирует ответы кандидатам.

Колонка «Плановое скрытие» заполняется по ответу админов на вопрос `C5`.
По строкам со «да» агент не поднимает тревогу о скрытом объявлении.

## Лист 4. «Баланс»

| Дата проверки | Аванс, ₽ | Кошелёк, ₽ | Метка Авито | Сообщили управляющему |
|---|---|---|---|---|
| 25.08 09:30 | 101 | 0 | Надо пополнить | да, 09:31 |

Порог для предупреждения: 500 ₽. Нужен, чтобы не сообщать об одном и
том же каждый день по десять раз и не пропустить ноль.

| График сменный, какие выходные? | «График 2/2, с 10:00 до 20:00» |

### Правило цитирования объявления

Три ответа выше отсылают к тексту объявления. Агент **не пишет** «посмотрите
в объявлении» — человек пришёл именно оттуда, и такой ответ читается как
отказ разговаривать. Вместо этого агент берёт текст объявления (он есть у
него через API, поле «Условия из объявления» на листе «Объявления») и
цитирует нужную строку, добавляя, где уместно, «подробно обсудим на
собеседовании».

Если в объявлении нужной строки нет — агент не додумывает, а спрашивает
управляющего и говорит кандидату, что уточнит.

### Правило про деньги

Агент называет только то, что дословно написано в объявлении или в этой
таблице. Никаких «примерно», «обычно выходит», «зависит от выработки».
Всё, чего здесь нет, — на собеседовании или через уточнение у человека.
