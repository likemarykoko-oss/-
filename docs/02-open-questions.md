# Что решено и что осталось

## Решено

| Вопрос | Решение |
|---|---|
| Кто принимает решение по мастерам | **Руководитель** смотрит фото работ и отвечает «да/нет». Агент делает только формальную проверку |
| Возраст 19–35 | **Мягкий ориентир.** Агент записывает и передаёт руководителю, не отказывает сам, в переписке возраст не звучит |
| Подключение к Авито | **Официальный Avito API** (мессенджер + объявления) |
| Руководитель и управляющая | **Один человек, один канал.** Три адресата свелись к двум: руководитель и чат «админы коко» |
| Кто знает занятость времени | **Админы.** Агент сначала спрашивает окна в чате, потом называет их кандидату. Своего расписания у агента нет |
| Кандидату не подошло окно | Агент передаёт админам контакт, дублирует дату и время и просит связаться. Сам другое время не подбирает |
| После записи модели | Агент спрашивает админов: объявление ещё актуально или все модели найдены и его скрываем |
| Баланс | Агент проверяет баланс ежедневно и предупреждает **до** того, как объявления скроются. **Порог предупреждения — 500 ₽** |
| Срок ответа админов | **2 рабочих часа** на запрос окон. Дальше напоминание в чат, через 4 часа — эскалация руководителю |
| Рабочее окно | Админы и руководитель — **10:00–20:00**. Все сроки считаются только внутри окна, ночью таймер стоит. Агент отвечает кандидатам круглосуточно, но людей не дёргает и время не обещает до 10:00 |
| Неполная анкета | Кандидата не сливаем: есть минимум (имя, телефон, специализация) — карточка уходит руководителю с пометкой, чего не хватает. Нет фото — предлагаем принести на собеседование |
| Имя агента | **Ника**, помощник руководителя. На прямой вопрос «вы бот?» отвечает честно |

---

## Осталось заполнить

**1. FAQ — заполнен полностью.** Стажировка, график 2/2, что взять на
собеседование, имя агента (Ника) и «услугу выполняет ученик под наставником»
внесены в тексты и промпт.

**2. Контакты и доступы**
- Telegram: чат руководителя и чат «админы коко» (ID или ссылки);
- доступ к кабинету Авито и ключи API (`client_id`, `client_secret`);
- есть ли у агента права скрывать объявления, или он ставит задачу человеку.

**3. Баланс**
- отдаёт ли Avito API баланс напрямую — проверим при интеграции. Если нет,
  проверка будет по кабинету, и способ зафиксируем отдельно.

**4. Сроки**
- за сколько отвечает администратор на заявку по обучению;
- отвечать ли агенту ночью и в выходные (рекомендую да: скорость ответа
  влияет на выдачу Авито).

**5. Модели**
- требования по каждому активному объявлению — дословно;
- политика по несовершеннолетним моделям.

**6. Собеседования**
- что кандидату взять с собой;
- адрес для сообщения кандидату.

**7. Анкета администратора**
Добавляем ли два вопроса — опыт и готовность к графику? Без них руководитель
всё равно спросит, и цикл удлинится на сутки.
