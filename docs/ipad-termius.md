# Настройка с iPad через Termius

Владелец работает с планшета: своего терминала нет, а серийная консоль Timeweb
коверкает вставку (в строку ввода попадают ответы терминала вида `1R2;126R2`).
Termius решает обе проблемы и даёт SSH-ключи, без которых Фазу 2 делать нельзя.

## Шаг 1 — установка

App Store → **Termius** (значок — синий терминал, разработчик Termius Corporation).
Бесплатного тарифа **Starter** достаточно: SSH, SFTP, вкладки, ключи.
Регистрация аккаунта необязательна — можно нажать «Skip» / «Continue without account».

## Шаг 2 — подключение по паролю

`Hosts` → **+** → `New Host`:

| Поле | Значение |
|---|---|
| Alias | `hermes` |
| Hostname / IP | `216.57.111.124` |
| Port | `22` |
| Username | `root` |
| Password | пароль от сервера |

Сохранить → тап по хосту. При первом подключении спросит про отпечаток ключа —
принять. Должно появиться приглашение `root@8851435-qm685785:~#`.

Если подключение не проходит с мобильного интернета или чужого Wi-Fi — сеть режет
22 порт. Проверить на другой сети; серийная консоль в панели Timeweb остаётся
запасным входом всегда.

## Шаг 3 — Фаза 0: ключ вместо пароля

**3.1.** В Termius: `Keychain` → **+** → `Generate key`.
Тип **ED25519**, имя `hermes_vps`. Сохранить.

**3.2.** Открыть созданный ключ → **Copy public key** (копируется строка,
начинающаяся с `ssh-ed25519 ...`).

**3.3.** В открытой сессии на сервере выполнить — вставив свой ключ вместо `<КЛЮЧ>`:

```bash
mkdir -p /root/.ssh && chmod 700 /root/.ssh
echo '<КЛЮЧ>' >> /root/.ssh/authorized_keys
chmod 600 /root/.ssh/authorized_keys
grep -c '^ssh-' /root/.ssh/authorized_keys
```

Последняя команда должна напечатать `1`. Кавычки вокруг `<КЛЮЧ>` обязательны.

**3.4.** В настройках хоста `hermes` в Termius: убрать пароль, выбрать ключ
`hermes_vps` в поле `Key`. Отключиться и подключиться заново.

**Проверка Фазы 0:** подключение проходит **без запроса пароля**.
Только после этого можно запускать Фазу 2.

## Шаг 4 — скрипты на сервер

Репозиторий публичный, поэтому скрипты тянутся напрямую:

```bash
cd /root
curl -fsSLO https://raw.githubusercontent.com/likemarykoko-oss/-/claude/hermes-server-setup-ycayqd/scripts/{00-check,10-base,20-security,30-hermes,set-env}.sh
chmod +x *.sh && ls -1 *.sh
```

Дальше — по `scripts/RUNBOOK.md`, начиная с Фазы 1.

## Полезное в Termius

- **Вставка:** долгий тап в терминале → `Paste`.
- **Ctrl и Tab:** на панели над клавиатурой (в консоли Timeweb их не было).
- **Вкладки:** несколько сессий сразу — удобно, когда одна занята установкой.
- **Не закрывай сессию во время Фазы 2** — пока не проверишь вход новой сессией.
