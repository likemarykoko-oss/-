# Установка — 15 минут, один раз

Только компьютер: Mac или Windows. Монтаж считается на вашей машине.

**Нужен именно Claude Code** — версия с терминалом и доступом к вашим файлам.
В обычном приложении Claude (просто чат) монтаж работать не будет: туда файлы
загружаются на сервер, и большое видео упирается в лимит 30 МБ.

## Шаг 1. Навык на место

Папку `skills/reels-motion` положите сюда:

**Mac:** `/Users/ВАШЕ_ИМЯ/.claude/skills/`
**Windows:** `C:\Users\ВАШЕ_ИМЯ\.claude\skills\`

Папка `.claude` скрытая. На маке: Finder → «Переход» → «Переход к папке» →
`~/.claude/skills` → Enter. Нет папки `skills` — создайте.

Или запустите `установить.sh` — он сделает это сам.

## Шаг 2. Два плагина

В Claude Code выполните по очереди:

```
/plugin marketplace add remotion-dev/claude-code-plugin
```
```
/plugin install remotion@remotion
```
```
/plugin install hyperframes@claude-plugins-official
```

**Remotion** — движок сборки и рендера видео.
**HyperFrames от HeyGen** — титры, анимации, переходы, графические карточки.

**Ошибка «Host key verification failed»?** Скажите Claude:
> настрой git на https для github и повтори установку плагина

**После установки перезапустите Claude Code** — иначе плагины не подключатся.

## Шаг 3. Программы

Скажите Claude:
> проверь, что нужно для навыка reels-motion, и установи чего не хватает

Нужны: **Node.js 22+** (движки), **ffmpeg** (видео), **Python + Pillow**
(графика), **whisper** (распознавание речи для привязки анимации к словам).
Всё бесплатно, без регистраций.

## Шаг 4. Проверка

Снимите вертикальное видео 20–30 секунд, положите в папку — например
`Документы/тест-ролик/` — и откройте Claude Code **в этой папке**:

```
cd ~/Documents/тест-ролик && claude
```

Дальше скажите:

> сделай анимированный монтаж, заголовок — «ваша фраза»

**Видео в чат не перетаскивайте.** Оно остаётся на диске, Claude открывает его сам.
Ошибка «exceeds 30 MB limit» означает ровно одно: вы пытаетесь загрузить файл
в переписку вместо того, чтобы дать путь к нему.

Первый ролик рендерится несколько минут. Дальше быстрее — стиль уже настроен.

## Если застряли

Скажите Claude: **«что-то не работает, разберись»** и покажите, что видите.
Он читает ошибки и чинит сам.
