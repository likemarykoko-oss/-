# Сложный монтаж с анимацией

Здесь текст не появляется, а **живёт**: выпрыгивает с пружиной, разъезжается,
считает цифры, уезжает за кадр. Это то, чего ffmpeg не умеет и ради чего
подключены Remotion и HyperFrames.

## Сначала реши, нужен ли этот навык

Не гони через анимацию весь ролик. Правило: **анимируется 10–15% хронометража** —
титул, одна-две вставки, финальная плашка. Остальное — чистое видео с речью.
Ролик, где движется каждый элемент, читается как шаблон из стоков.

Если человеку нужен только текст поверх видео и обычные субтитры — это не сюда:
такая задача решается за две минуты простым наложением, а здесь рендер идёт минуты.
Ролик, где движется каждый элемент, читается как шаблон из стоков.

## Что лежит в комплекте

- `fonts/woff2/` — **26 свободных шрифтов** для композиций (`fonts/ttf/` — те же
  в формате для Python). Все с кириллицей, кроме BebasNeue — у него только латиница.
  Подключай через `@font-face` с относительным путём, внешние URL запрещены.
- `инфографика/` рядом с навыком — **7 готовых карточек**: титул, счётчик,
  чек-лист, сравнение, скриншот, лоуэр-третий, финал. Копируй фрагмент, меняй
  плейсхолдеры в `{{фигурных скобках}}`, вешай анимацию из комментария сверху.
  Не изобретай карточку с нуля, пока не проверил, что подходящей нет.

Шрифты по умолчанию: **Oswald** (заголовки, капс, тени без обводки),
**Caveat** (рукописный акцент), **Inter** или **GolosText** (мелкий текст).
Bebas Neue для русского не годится — кириллицы в нём нет, замена Oswald.

## Стиль берётся из файла, а не из головы

`VIDEO_STYLE_GUIDE.md` лежит рядом с этим навыком и в `~/smm/`. Читай его перед
каждым роликом: шрифты, цвета, тени, ритм, безопасные зоны, чего не делаем.
Внёс изменение в стиль — правь стайлгайд, а не отдельный ролик.

## Материалы к ролику — в одну папку

```
videos/<название>/
├── source.mp4          исходник
├── reference-01.mp4    что берём: субтитры
├── reference-02.mp4    что берём: ритм склеек
├── logo.png · screenshot-01.png · music.mp3
```
От референса берём **конкретное**, а не «сделай как здесь»: из одного —
расположение субтитров, из другого — ритм, из третьего — анимацию заголовка.
Чужие логотипы и фирменные элементы не копируем.

## Главный приём: привязка к словам

Эффекты вешаются **на фразы, а не на секунды**. «На словах про 9000 писем —
счётчик», «на призыве — плашка». Перемонтировала — эффект уехал вместе с речью.

## Правки — только точечные

Когда она просит переделать, меняй **строго названное** и говори себе:
«весь остальной монтаж без изменений». Это защищает то, что уже получилось.

## Как устроен конвейер

```
съёмка  →  prep.py (речь → speech.srt, паузы вырезаны, вертикаль, base.mp4)
                 ↓
        HyperFrames / Remotion  →  графика поверх видео
                 ↓
        готовый ролик
```

Анимация рендерится **отдельным прозрачным слоем**, а не поверх готового ролика:
так её можно переделать, не пересобирая всё, и один и тот же титул переиспользуется
в других видео.

## Шаг 1. Подготовь исходник

```bash
python3 ~/.claude/skills/reels-motion/scripts/prep.py дубль.MOV
```

Одна команда делает всё: распознаёт речь (локально, без ключей), вырезает паузы,
приводит к вертикали 1080×1920 и перекодирует с частыми ключевыми кадрами —
без этого видео «замерзает» под графикой при рендере.

На выходе рядом с исходником: `base.mp4` и `speech.srt`.

**`speech.srt` обязательно вычитай перед сборкой.** Распознавание путает термины
и имена («Claude Code» превращается в «платкод»). Тайминги не трогай, правь только текст.

Не вырезать паузы: `--no-cut`.

## Шаг 2. Собери анимированный слой

### Вариант А — Remotion (React, полный контроль)

```bash
npx create-video@latest --yes --blank --no-tailwind title-anim && cd title-anim && npm i
```
Скопируй `templates/AnimatedTitle.tsx` из этого навыка в `src/`, подключи в `Root.tsx`,
поставь размер композиции 1080×1920 и рендери **с прозрачностью**:

```bash
npx remotion render --image-format=png --pixel-format=yuva444p10le \
  --codec=prores --prores-profile=4444 AnimatedTitle титул.mov
```

Подробности — в скиллах плагина: `remotion-create`, `remotion-markup`,
`remotion-captions` (кинетические субтитры), `remotion-render`.

### Вариант Б — HyperFrames (HTML + GSAP, есть готовый каталог движений)

```bash
npx hyperframes init title-anim
npx hyperframes catalog --query "заголовок выезжает по строкам"
npx hyperframes add <название-примитива>
npx hyperframes check
npx hyperframes render
```
Сильная сторона — каталог готовых движений: не сочиняй анимацию руками, сначала
спроси каталог. Скиллы плагина: `hyperframes-core`, `hyperframes-animation`,
`motion-graphics`, `embedded-captions`.

Когда что: **Remotion** — если нужен точный контроль и переиспользуемый шаблон под
рубрику. **HyperFrames** — если нужно быстро и красиво из готовых примитивов.

## Шаг 3. Наложи на видео

```bash
python3 ~/.claude/skills/reels-motion/scripts/overlay_anim.py \
    база.mp4 готово.mp4 --layer титул.mov --at 0.4
```
Несколько слоёв — повторяй пары `--layer` и `--at`.

Формат слоя: **ProRes 4444 (.mov)**. WebM с прозрачностью на этом маке не соберётся —
в ffmpeg нет vp9, не трать на это время.

## Вставки: скриншоты, доп. видео, картинки

Это то, что превращает говорящую голову в доказательство. Правило простое:
**на словах про результат — показать результат.**

Материалы человека кладутся в `media/` внутри папки ролика и оттуда попадают
в карточку. Три рабочих паттерна:

**1. Скриншот в стеклянной рамке** — «вот так стало»:
```html
<div class="glass" id="card-05-shot" style="padding:18px;">
  <img src="media/inbox-after.png" style="width:100%;border-radius:18px;display:block;">
  <div class="kick" style="margin-top:14px;">папки собрались сами</div>
</div>
```
Анимация: `scale-pop` при появлении плюс медленный наезд (`scale 1 → 1.06` за всё
время карточки). Статичный скриншот в кадре мёртв, лёгкое движение его оживляет.

**2. До / после** — два скриншота рядом, второй въезжает поверх первого
(`mask-reveal` слева направо). Самый сильный формат для «я навела порядок».

**3. Доп. видео картинкой-в-картинке** — экранная запись поверх её лица:
```html
<video src="media/screen-record.mp4" muted playsinline
       data-start="18.0" data-duration="4.5" data-track-index="3"
       style="position:absolute;right:40px;top:220px;width:420px;border-radius:24px;"></video>
```
Держать 3–5 секунд, не дольше: за это время зритель считывает суть, дальше
начинает скучать. Звук у вставки всегда выключен — говорит она.

Чего не делать: стоковых картинок и чужих логотипов. Пустая карточка честнее
безликой картинки из интернета.

## Правила, без которых получится дёшево

1. **Одна шрифтовая пара на ролик** — из `fonts/woff2/` рядом с навыком.
   По умолчанию Oswald (заголовки) + Inter или GolosText (подписи) + Caveat
   (рукописная строка). Разные шрифты в титуле и подписях выдают склейку из кусков.
2. **Цвета из `VIDEO_STYLE_GUIDE.md`** — акцент `#FF7A00`, подсветка `#FFE24D`,
   поверх светлого кадра акцентом идёт жёлтый. Не изобретай палитру под каждый ролик.
3. **Пружина, а не линейность.** Появление 0.25–0.4 сек с лёгким перелётом
   (масштаб уходит за 1.05 и возвращается). Линейное появление выглядит мёртвым.
4. **Безопасные поля:** низ 18%, верх 10%. Анимация не должна залетать под интерфейс.
5. **Уходить тоже надо.** Титул не исчезает мгновенно — уезжает или растворяется за 0.2 сек.
6. **Тишина между движениями.** Две анимации подряд без паузы дерутся за внимание.

## Что просить у HyperFrames и Remotion, а что нет

Просить: анимированный титул рубрики, счётчик цифр, кинетические субтитры для хука,
заставку с логотипом, анимированную плашку «до/после», переход между сценами.

Не просить: обычные субтитры на весь ролик — рендер каждой строки стоит времени,
а пользы столько же, сколько от вжигания их одной командой; простое затемнение;
статичную картинку без движения.

## Проверка перед выдачей

1. Целиком со звуком.
2. Без звука — понятно ли по тексту.
3. Первые 2 секунды: хук читается?
4. Текст не закрывает лицо и не лезет под интерфейс Reels.
5. Опечатки: Whisper путает термины («Claude Code» → «платкод»). Расшифровку
   вычитывай **всегда**, до сборки.
