# Runbook: Antigravity CLI (`agy`) как внешний инструмент агента

`agy` — официальный агентный CLI от Google (Antigravity), работает на Gemini: как
Claude Code / Gemini CLI, только от Google. Умеет рассуждать, выполнять задачи в
терминале и **генерировать изображения** на квоте Google-аккаунта (Gemini Pro / Google
AI Pro). Ставится напрямую от Google, авторизуется Google-логином.

Ключевая идея: у Hermes-агента есть terminal-тулсет, поэтому `agy` не обязательно
прокидывать «внутрь» Hermes отдельным плагином — **агент просто вызывает `agy` в
терминале как внешнюю команду** (так проще всего и работает на стоковом Hermes). Именно
так это и используется у нас: `agy` установлен и авторизован, агент дёргает его субпроцессом.

## 1. Установка (официальный бинарь Google)

```bash
ssh hermes-vps "curl -fsSL https://antigravity.google/cli/install.sh | bash"
```

Бинарь ложится в `~/.local/bin/agy`. Проверка:
```bash
ssh hermes-vps "HOME=/root ~/.local/bin/agy --version"
```
⚠ `~/.local/bin` может не быть в PATH — вызывай полным путём `/root/.local/bin/agy` и
задавай `HOME=/root` (agy хранит профиль/токен в `$HOME/.gemini/antigravity-cli/`).

## 2. Авторизация Google на headless-сервере (device-флоу)

```bash
ssh -t hermes-vps "HOME=/root /root/.local/bin/agy"
```
При первом запуске выбери **Google OAuth**. Браузера на сервере нет — CLI печатает URL и
код: пользователь открывает URL на своей машине, входит в Google-аккаунт с доступом к
Gemini, вводит код обратно в терминал. Токен сохранится в `~/.gemini/antigravity-cli/`
(`/logout` — выйти). После этого `agy` работает без интерактива.

## 3. Использование как внешнего CLI (что делает агент)

**Одноразовый запрос (non-interactive, для агента и скриптов):**
```bash
HOME=/root /root/.local/bin/agy --print --dangerously-skip-permissions \
  --print-timeout 10m [--model <модель>] "<запрос>"
```
- `--print` (`-p`) — выполнить один промпт и напечатать результат (не открывать сессию);
- `--dangerously-skip-permissions` — не спрашивать подтверждений на каждый инструмент
  (обязательно в headless, иначе зависнет на промпте);
- `--print-timeout` — таймаут ожидания (генерация картинки бывает долгой, 10m с запасом);
- `--model` — опционально; список: `agy models`.

**Генерация изображения:** дай текст-в-картинку промпт — `agy` сгенерит и сохранит файл,
напечатав строку вида `Generated image is saved at /abs/path.jpg`:
```bash
HOME=/root /root/.local/bin/agy --print --dangerously-skip-permissions --print-timeout 10m \
  "Сгенерируй изображение: рыжий кот в шляпе, соотношение 16:9"
```
Агент парсит путь из вывода и отправляет картинку пользователю в Telegram.

**Общие агентные задачи:** `agy -p "..."` — разовый Gemini-запрос; интерактивная
сессия — просто `agy` (или `agy -c` продолжить последнюю).

## 4. Как это подключено к Hermes

Два способа, оба валидны:
- **Просто через терминал (рекомендуется для семинара):** ничего настраивать не надо —
  агент вызывает `agy` как внешнюю команду (см. выше). Работает на стоковом Hermes.
  В инструкции агента/`SOUL.md` можно явно написать: «для генерации картинок используй
  `agy --print …`».
- **Нативным image-бэкендом Hermes:** через плагин `image_gen` (`antigravity-cli`),
  который оборачивает ровно этот вызов `agy`. Плагин НЕ входит в стоковый Hermes —
  нужен его отдельный источник (`hermes plugins install <git>`). Если источника нет,
  используй терминальный способ — результат тот же.

## 5. Безопасность
- `--dangerously-skip-permissions` снимает подтверждения только для процесса `agy`;
  давай ему осмысленные промпты, не гоняй произвольный неизвестный ввод.
- Google-токен (`~/.gemini/antigravity-cli/`) — секрет, в чат/логи не выводить.
- `HOME=/root` фиксирует, где agy ищет токен и рабочую папку (`brain/`); не меняй на лету.
