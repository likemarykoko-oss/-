Hermes: свой AI-агент
на своём сервере

От пустого VPS до личного агента в Telegram — с голосом, памятью, веб-поиском и автоматизациями. За один вечер.

Что это

Hermes — «агент, который растёт с тобой»

  • Open-source агент от Nous Research (MIT-лицензия) — никакого вендор-лока
  • Память между сессиями: помнит тебя, твои предпочтения и договорённости
  • Скиллы: сам создаёт себе инструкции из повторяющихся задач
  • Кроны: пишет тебе сам — дайджесты, напоминания, отчёты
  • 20+ мессенджеров, 60+ инструментов, любой LLM на выбор

Магия раздатки

Настраивает твой Claude — по скиллу

Тебе не нужно быть админом. Даёшь своему Claude-агенту скилл-раздатку и IP свежего сервера:

«Вот скилл hermes-vps-setup и сервер 1.2.3.4. Действуй.»
  • Агент идёт по фазам 0–8 и сам всё настраивает
  • У тебя спрашивает только API-ключи и решения
  • Каждый шаг проверяется, ничего не делается «молча»
  • Все известные грабли уже вшиты в скилл с пометкой ⚠
Фазы 0–2

Фундамент: доступ и безопасность

SSH-ключ вместо пароля — пароль отключается совсем, брутфорсить нечего
Фаервол UFW — всё входящее закрыто, открыт только SSH
fail2ban — автобан за перебор паролей
Автообновления безопасности — сервер патчится сам
Грабли из жизни: порт SSH открывать через ufw allow, а не ufw limit — «лимит» начинает банить твоего же агента за активную работу. Проверено болью.
Фаза 3

Установка Hermes — одна команда

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
  • Ставит всё сама: Python, Node, ffmpeg, браузер для агента
  • Появляется CLI hermes и домашняя папка ~/.hermes
  • Гейтвей — это systemd-сервис: переживает ребуты, стартует сам
  • Проверка здоровья: hermes doctor

Фаза 5

Telegram: бот рождается

@BotFather → /newbot → токен
Вайтлист: бот отвечает только тебе (fail-closed: чужим — отказ)
Доступ близким — по одноразовым pairing-кодам, без ковыряния в id
Гейтвей в systemd → первое сообщение боту 🎉
Грабли: бот молчит, в логах «Connecting to Telegram (attempt 1/8)…» — это зависший discovery запасных IP. Лечится одной командой (в скилле есть).
Фаза 6

Голос в обе стороны

🎙 Ты — голосом

Groq Whisper распознаёт (быстро, бесплатно). Если Groq недоступен — локальный Whisper на самом сервере. Файлы любой длины — нарезка автоматом.

🔊 Бот — голосом

Edge TTS: без ключей и регистраций, десятки голосов на русском. Скажи «ответь голосом» — и агент говорит.

  • Надиктовал задачу по дороге → бот сделал → ответил голосом
Фаза 7

Глаза в интернет + Google-жизнь

  • Поиск: Brave Search (2000 запросов/мес бесплатно) или DuckDuckGo вовсе без ключа
  • Чтение страниц: Firecrawl — любой URL превращается в чистый текст для агента
  • Google Workspace (опция): почта, календарь, диск, таблицы через CLI gog
Грабли Google: OAuth-приложение обязательно перевести в статус In production — в режиме Testing токены протухают через 7 дней, и «всё сломалось само».

Фаза 7¾ · любимая

Оживление

Личность — SOUL.md. Имя, характер, тон. Один файл — и это уже «твой» агент, а не ассистент из коробки.
Дом — /sethome. Чат, куда бот пишет по своей инициативе.
Первый крон — просто попроси. «Каждое утро в 9 присылай план дня» — бот сам создаст себе расписание.
Память. «Запомни это на будущее» — и он помнит. Навсегда.
Философия

Агент, который растёт

  • Память — это «что»: факты о тебе, проектах, договорённостях
  • Скиллы — это «как»: пошаговые рецепты, которые агент пишет себе сам
  • Правило: повторил задачу из 5+ шагов дважды → «создай себе скилл»
  • Дальше — просто /имя-скилла: неделя работы превращается в команду
Через месяц твой Hermes — не тот, что после установки: он «оброс» твоими скиллами и памятью. Это и есть главное отличие от чат-ботов.
Экономика

Токены под контролем

  • /usage — расход прямо в чате
  • /insights — анализ трат за 30 дней
  • /compress — ужать длинную сессию
  • Бесплатные лапы: Nous :free, OpenRouter :free, Groq
  • Подписки в дело: ChatGPT Plus через Codex OAuth
  • Частая смена модели в сессии = сброс кэша = дороже
Безопасность

Правила выживания агента

  • Опасные команды — только с твоего «да» в чате (режим подтверждений)
  • Доступ к боту — строго вайтлист или pairing-коды
  • Никогда: «отвечать всем» у бота с доступом к терминалу
  • Периодически просматривай скиллы, которые агент написал себе сам
  • Перед обновлением — hermes backup, копию — к себе на компьютер
  • Параноик-режим: команды в Docker-песочнице (terminal.backend: docker)
