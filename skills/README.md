# Раздатка семинара «Hermes: свой AI-агент на своём сервере»

Комплект для участников: скилл-раздатки для их Claude-агента + презентация ведущего.

## Что кому даём

| Файл | Кому | Зачем |
|---|---|---|
| `hermes-vps-setup.skill` | участникам | Основная раздатка: настройка VPS «под ключ» |
| `hermes-kilocode-opencode.skill` | участникам (опция) | Дополнение: провайдеры Kilocode и OpenCode Zen |
| `hermes-seminar-presentation.html` | ведущему | Презентация, 18 слайдов, открывается в браузере |

Исходники скиллов лежат рядом в одноимённых папках — их и правим, `.skill` пересобирается
из них.

## Как участник этим пользуется

Даёт своему Claude-агенту `.skill`-файл и говорит:

> «Вот скилл hermes-vps-setup и сервер 1.2.3.4. Настрой Hermes, действуй по скиллу.»

Агент ведёт по фазам, останавливаясь только чтобы спросить API-ключи и решения.

## Что внутри основного скилла

**База (Фазы 0–9)** — рабочий агент в Telegram:
0. SSH-ключ вместо пароля
1. Базовая настройка сервера
2. Безопасность: sshd-харденинг, UFW, fail2ban, автообновления
3. Установка Hermes
4. «Мозг»: LLM-провайдер + fallback-цепочка
4½. Улучшенная память Hindsight (локально, опционально)
5. Telegram-бот
6. Голос: распознавание и голосовые ответы
7. Веб-поиск и парсинг
8. Оживление: личность (SOUL.md), домашний канал, первый крон
9. Финальная проверка, бэкап и отчёт

**Опциональные расширения (в конце, по желанию):**
- A — Google Workspace (Gmail/Calendar/Drive через `gog`)
- B — Генерация изображений (Codex или Antigravity CLI)
- C — Продвинутые инструменты (CloakBrowser, yt-dlp, NotebookLM)

Справочники в `hermes-vps-setup/references/`: `security.md`, `providers.md`,
`web-tools.md`, `hindsight-memory.md`, `google-workspace.md`, `image-gen.md`,
`antigravity-cli.md`, `power-tools.md`. Скрипт голоса — `scripts/hermes-stt-wrapper.py`.

## Что понадобится участнику

Обязательный минимум: доступ к серверу, токен Telegram-бота, свой user id, один
LLM-провайдер. Остальное (голос, поиск, парсинг, память, расширения) добавляется теми же
фазами в любой момент.

## Статус проверки

Прогонялось на чистом Ubuntu 24.04 (Linode), плюс независимая сверка всех утверждений
по исходникам Hermes и боевому серверу. Найденные грабли вшиты в тексты пометками ⚠.

**Проверено вживую (end-to-end):** SSH-харденинг (пароль отключается, ключ работает) ·
установка Hermes и зависимостей · TTS `edge` (без ключа) · веб-бэкенды `brave-free`/`ddgs`/
`firecrawl` · **Hindsight локально** — полный цикл: retain → граф фактов → recall → ответ
агента, плюс systemd-юнит и переживание рестарта · CloakBrowser (стелс-Chromium стартует) ·
yt-dlp + POT-провайдер (плагин подхватывается) · NotebookLM CLI · CLIProxy (контейнер,
порт, конфиг) · `@kilocode/cli` · ключи конфигов провайдеров и image_gen.

**Проверено по исходникам/справке, но не прогонялось целиком:** Telegram-бот (нужен живой
токен пользователя) · STT-обёртка Groq→faster-whisper (прогнан упрощённый вариант
`stt.provider groq`) · fallback-цепочка · Google Workspace (`gog`) и Antigravity (`agy`) —
сверялись на боевом сервере, на чистом боксе не ставились · Codex device-auth.

**Не проверялось:** облачный режим Hindsight (нужен свой ключ) · полностью локальный
вариант с Ollama (нужен бокс от 8–16 ГБ RAM).
