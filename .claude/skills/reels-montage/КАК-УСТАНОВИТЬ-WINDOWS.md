# Монтаж рилсов на Windows — установка по шагам

Один раз минут на пятнадцать. После этого монтаж идёт прямо на твоём компьютере:
файлы любого размера, никуда ничего не загружается, лимитов нет.

## Шаг 1. Поставь Claude Code на компьютер

Скачай с **claude.ai/download**, установи, войди в свой аккаунт.

Это то же самое, чем ты пользуешься в браузере, только работает на твоей машине —
и поэтому видит твои файлы.

## Шаг 2. Положи папку навыка на место

Нужна папка `reels-montage` (она в архиве рядом с этим файлом).

Открой проводник, вставь в адресную строку и нажми Enter:

```
%USERPROFILE%\.claude\skills
```

Если такой папки нет — создай её вручную: заходи в `C:\Users\Илья`, делай папку
`.claude`, внутри неё `skills`. Точка в начале имени обязательна.

Положи `reels-montage` целиком внутрь. Должно получиться так:

```
C:\Users\Илья\.claude\skills\reels-montage\SKILL.md
C:\Users\Илья\.claude\skills\reels-montage\scripts\
```

## Шаг 3. Поставь программы

Открой Claude Code и напиши одну фразу:

> проверь, что нужно для навыка монтажа, и установи

Он всё сделает сам. Поставит Python, если его нет, потом ffmpeg — это программа,
которая режет и собирает видео, — потом библиотеки и модель распознавания речи.

Модель весит около полутора гигабайт и качается один раз. Дальше она лежит
на диске и больше не скачивается никогда.

**Важно:** если он скажет, что поставил Python или ffmpeg и просит перезапустить —
закрой Claude Code и открой заново. Windows показывает новые программы только
в новом окне. Это нормально и бывает один раз.

Если хочется сделать руками, без Claude — открой PowerShell и вставь:

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.claude\skills\reels-montage\scripts\setup.ps1"
```

## Шаг 4. Работай

Теперь можно просто называть путь к файлу:

> разбери смыслы вот этого видео: C:\Users\Илья\Desktop\оБУЧЕНИЕ ии\КО-КО\ko-ko.mp4

Путь удобно копировать так: щёлкни по файлу правой кнопкой с зажатым Shift →
«Копировать как путь».

Дальше обычными словами:

- «наложи на это видео текст: Я делала это полгода неправильно»
- «сделай субтитры к этому ролику»
- «расшифруй, что я тут наговорила»
- «нарежь этот длинный дубль на три коротких клипа»
- «переделай горизонтальное видео в вертикальное для рилса»

## Про шрифты

Посмотреть, что есть: **«покажи, какие шрифты есть для монтажа»**.

Добавить свой: **«добавь этот шрифт для монтажа»** и путь к файлу.
Подходят `.ttf`, `.otf`, `.woff2`. Claude сразу проверит, есть ли в шрифте
русские буквы — если нет, текст сломается, и он об этом скажет.

Размеры, цвета и обводку меняет по просьбе: «сделай текст крупнее»,
«убери жёлтую плашку», «сделай субтитры белыми без капса».

## Если что-то не так

**«ffmpeg не найден»** — закрой и открой Claude Code. Почти всегда дело в этом.

**Первый монтаж думает долго** — качается модель распознавания. Один раз.

**В расшифровке ошибки в именах** — скажи, как правильно пишется, он поправит.
Пересчитывать речь заново не придётся.

## Одно правило, которое важнее настроек

Внутри одной рубрики оформление не меняем. Одинаковый текст на всех роликах —
это узнаваемость: человек видит кадр в ленте и понимает, что это ты, ещё до того,
как прочитает.
