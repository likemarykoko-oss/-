# Монтаж рилсов

Ты умеешь монтировать видео прямо на её компьютере: наложить текст, распознать речь,
вжечь субтитры, нарезать длинное видео на клипы. Всё бесплатно и локально —
видео никуда не загружается, ключи не нужны.

## Перед первым запуском

```bash
bash ~/.claude/skills/reels-montage/scripts/setup.sh
```

Ставит ffmpeg, Pillow, fontTools и распознавание речи, потом скачивает модель.
Делается один раз, занимает несколько минут. Скажи человеку одной строкой,
что ставишь программы для монтажа, и просто сделай это — команды показывать не нужно.

Проверить, чего не хватает, без установки:
```bash
ffmpeg -version >/dev/null 2>&1 && echo "ffmpeg есть" || echo "нужен ffmpeg"
python3 -c "import PIL, faster_whisper" 2>/dev/null && echo "остальное есть" || echo "нужен setup.sh"
```

Дальше все команды запускай из папки скрипта:
`cd ~/.claude/skills/reels-montage/scripts`

## Задача 1. Текст на видео (самое частое)

```bash
python3 reels_text.py вход.mp4 выход.mp4 --hook "Я делала это полгода неправильно"
```

Что происходит: видео приводится к вертикали 1080×1920, поверх ложится крупный
текст на первые 3 секунды. Текст не залезает в интерфейс Instagram — нижние 18%
и верхние 10% экрана оставлены пустыми.

Несколько надписей по времени — через файл `blocks.json`:
```json
[{"t":0,"d":3,"text":"Клиент попросил повторить\nрекламу за 300 тысяч","style":"hook","pos":"center"},
 {"t":3,"d":2.5,"text":"я сделала за вечер","style":"plate","pos":"bottom"}]
```
```bash
python3 reels_text.py вход.mp4 выход.mp4 --json blocks.json
```
`t` — на какой секунде появится, `d` — сколько секунд держится,
`pos` — `center`, `top` или `bottom`.

## Задача 2. Субтитры по речи — одна команда

```bash
python3 subtitles.py видео.mp4 готово.mp4
python3 subtitles.py видео.mp4 готово.mp4 --hook "Я делала это полгода неправильно"
```

Речь распознаётся сама — отдельный шаг не нужен, ключ не нужен, интернет нужен
только один раз, когда качается модель. Субтитры разбиваются на фразы по 3–4 слова,
разрыв ставится там, где человек делает паузу, а не по счётчику символов.
Пока висит хук, субтитры молчат — в кадре всегда одна надпись.

Расшифровка кладётся рядом с результатом (`готово.words.json`). Если человек
попросит поменять хук или стиль — второй прогон уже мгновенный, речь не считается заново:
```bash
python3 subtitles.py видео.mp4 готово2.mp4 --words готово.words.json --hook "другой хук"
```

Полезное:
- `--max-words 3` — короче фразы, быстрее ритм
- `--model large-v3` — точнее, но раза в два дольше; бери, если в речи много терминов или имён
- `--language auto` — если человек говорит не по-русски

## Задача 3. Расшифровка отдельно

Нужна, когда надо прочитать текст ролика — выбрать сильные куски, вытащить цитату,
написать описание к посту:

```bash
python3 transcribe.py видео.mp4 --out words.json
```

Модель по умолчанию `medium`: минута речи считается примерно минуту, русский
разбирает хорошо. `tiny` и `base` — быстро и грязно, `large-v3` — точнее и медленнее.

## Задача 4. Нарезать длинный дубль

```bash
python3 transcribe.py дубль.mp4 --out words.json
```
Прочитай расшифровку сама и выбери сильные куски — законченная мысль,
сильная фраза в начале, без «эээ» на входе, 20–40 секунд. Потом:
```bash
python3 cut.py дубль.mp4 клип.mp4 --parts '[[12.4,28.9],[95,112.3]]'
python3 subtitles.py клип.mp4 готово.mp4 --hook "хук"
```
**Никогда не режь мысль пополам ради длины.** Лучше клип короче, но целый.

Таймкоды бери из `words.json` — там у каждого слова есть начало и конец.
Режь по паузам между фразами, а не по середине слова.

## Шрифты и стили — это главное, что настраивают под себя

Посмотреть, что есть:
```bash
python3 reels_text.py --list-fonts
```
Добавить свой шрифт (в том числе с сайта, в формате woff2 — переведётся сам):
```bash
python3 reels_text.py --add-font ~/Downloads/МойШрифт.woff2
```
Скрипт сразу скажет, есть ли в шрифте кириллица. Если нет — русский текст сломается,
бери другой.

Разово поменять шрифт для одного ролика:
```bash
python3 reels_text.py вход.mp4 выход.mp4 --hook "текст" --font Onest
```

Насовсем — правь `scripts/styles.json`. Скрипт трогать не нужно, там только шрифты,
размеры и цвета:

| Поле | Что значит |
|---|---|
| `font` | имя шрифта из `--list-fonts` |
| `size` | размер букв (92 — крупный хук, 58 — субтитры) |
| `fill` | цвет текста |
| `stroke` / `stroke_w` | цвет и толщина обводки; обводка нужна, чтобы текст читался на любом фоне |
| `box` | цвет плашки под текстом, `null` — без плашки |
| `width` | сколько процентов ширины экрана занимает текст |
| `case` | `upper` — КАПСОМ, `none` — как написано |

Готовые стили: `hook` (крупный белый с обводкой), `sub` (субтитры),
`plate` (жёлтая плашка), `quote` (курсивом), `code` (моноширинный), `clean`.

Субтитры настраиваются в пресете `sub`: «сделай субтитры без капса» — это
`"case": "none"`, «белыми без обводки» — `"stroke": null`.

**Правило: внутри одной рубрики стиль не меняем.** Одинаковый текст на всех роликах —
это и есть узнаваемость. Меняешь стиль — меняешь его один раз в `styles.json`,
и все следующие ролики выходят по-новому.

## Если что-то пошло не так

- **«речь не распознана»** — в ролике тихо или это музыка без слов. Предложи
  наложить текст руками через `reels_text.py`.
- **Расшифровка с ошибками** — переспроси у человека, как правильно пишутся имена
  и названия, и поправь `words.json` руками: это обычный текстовый файл.
  Или прогони с `--model large-v3`.
- **Долго считает** — это нормально для первого раза: качается модель. Скажи об этом
  заранее, чтобы человек не думал, что всё зависло.

## Как разговаривать с человеком

Она не программистка. Не показывай ей команды без надобности — просто сделай
и покажи готовый файл. Если чего-то не хватает — скажи одной строкой, что именно
ставишь, и поставь сама.
