# Шрифты — 26 штук, все можно использовать в коммерции

Смотрите **КАТАЛОГ-ШРИФТОВ.png** — там все начертания на русском тексте.
Файлы лежат в `skills/reels-motion/fonts/`: `woff2` для видео-композиций,
`ttf` — если понадобится где-то ещё.

## Заголовки и цифры
| Шрифт | Характер |
|---|---|
| **Oswald** | узкий высокий капс — главный рабочий заголовок, аналог Bebas с кириллицей |
| **AlumniSans** | узкий, чуть мягче Oswald, хорош для длинных строк |
| **RussoOne** | плотный, тяжёлый, для коротких ударных слов |
| **Unbounded** | геометрический, современный, для «технологичной» подачи |
| **YesevaOne** | с засечками, дорогой и женственный |
| **BebasNeue** | **только латиница**, русских букв нет — для англоязычных слов |

## Основной текст и подписи
**Inter** · **Manrope** · **GolosText** · **Rubik** · **Onest** · **Montserrat** ·
**Commissioner** · **Evolventa**

GolosText и Onest сделаны с расчётом на русский — берите их, если сомневаетесь.

## Рукописные — для живой строки под заголовком
**Caveat** (аккуратный) · **MarckScript** (тонкий) · **BadScript** (небрежный) ·
**Neucha** (детский, тёплый) · **Pacifico** (жирный, яркий) ·
**RuslanDisplay** (декоративный, только для одного слова)

## Засечки и моноширинные
**PlayfairDisplay** · **Literata** · **PTSerif** · **CormorantItalic** ·
**JetBrainsMono** · **RobotoMono**

Моноширинные — для кода и «технических» вставок.

## Как выбрать пару

Берите **два шрифта на ролик**: один для заголовков, один для подписей.
Третий — только рукописный акцент, одной строкой.

Готовые пары:
- **Oswald + Inter** — универсальная, деловая
- **RussoOne + GolosText** — жёсткая, для сильных заявлений
- **Unbounded + Manrope** — технологичная
- **YesevaOne + Literata** — дорогая, женственная
- любая пара **+ Caveat** одной строкой

## Как поменять шрифт

Скажите Claude: **«поменяй заголовки на RussoOne»** — он подставит его во все
карточки. Или впишите название в `VIDEO_STYLE_GUIDE.md`, и он будет брать
его по умолчанию.
